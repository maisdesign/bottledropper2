# Etimué Bottle Dropper 2

A small arcade-style web game originally created for the **Etimué** pub.

The player has to drop bottles into the right crates and avoid mistakes, with increasing difficulty and a simple score/leaderboard system.  
The project started as a fun in-house game for customers and then evolved into a full web app.

> ITA: gioco arcade web pensato per intrattenere i clienti del pub Etimué, con logica di punteggio e difficoltà crescente.

---

## 🎮 Features

- Arcade gameplay (bottle dropping / matching)
- Score system and basic leaderboard logic
- Keyboard / mouse controls (and easily extendable to touch)
- Progressive difficulty
- Lightweight front-end, runs entirely in the browser

---

## 🧱 Tech Stack

- **HTML5** (markup)
- **CSS3** (layout & basic animations)
- **JavaScript (vanilla)** for game logic
- PWA basics (manifest, icons, installable behaviour) – if/when enabled
